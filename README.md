# Advanced-JAVA

A comprehensive Java and Spring ecosystem learning repository covering core Java database connectivity, enterprise application development, RESTful services, security, microservices, and modern AI-powered applications.

## Technologies Covered

### 1. JDBC (Java Database Connectivity)

* Database connectivity using Java
* CRUD Operations
* PreparedStatement
* CallableStatement
* Batch Processing
* Transaction Management
* ResultSet Handling

### 2. Spring JDBC

* JdbcTemplate
* NamedParameterJdbcTemplate
* CRUD Operations
* RowMapper
* BeanPropertyRowMapper
* Exception Handling
* DAO Layer Implementation

### 3. Hibernate ORM

* Object Relational Mapping (ORM)
* Entity Mapping
* HQL (Hibernate Query Language)
* Criteria API
* Relationships Mapping
* Caching Concepts
* Transaction Management

### 4. Spring ORM

* Hibernate Integration with Spring
* LocalSessionFactoryBean
* HibernateTemplate
* Transaction Management
* DAO Layer Development

### 5. Servlets & JSP

* Servlet Lifecycle
* Request & Response Handling
* Session Management
* Cookies
* JSP Directives
* JSTL
* MVC Architecture Basics

### 6. Spring Core

* IoC (Inversion of Control)
* Dependency Injection
* Bean Lifecycle
* Bean Scopes
* Autowiring
* Java Configuration
* XML Configuration

### 7. Spring Framework

* Core Container
* Spring Beans
* Spring Context
* Spring Expression Language (SpEL)
* Event Handling
* Resource Management

### 8. Spring MVC

* MVC Architecture
* Controllers
* View Resolvers
* Form Handling
* Validation
* Exception Handling
* CRUD Web Applications

### 9. REST API Development

* REST Principles
* HTTP Methods
* Request Mapping
* Path Variables
* Query Parameters
* ResponseEntity
* Exception Handling
* API Documentation

### 10. Spring Data JPA

* Repository Pattern
* JpaRepository
* Custom Queries
* Pagination & Sorting

* Native Queries

### 11. Spring Boot

* Auto Configuration
* Starter Dependencies
* Profiles
* Configuration Properties
* Logging
* Actuator
* Spring Boot Testing

### 12. Spring Security

* Authentication
* Authorization
* Role-Based Access Control

### 13. Microservices

* Service Discovery
* API Gateway

* Distributed Logging

### 14. Spring AI

* AI Integration with Spring
